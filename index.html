About

Exam Reader adapts the presentation of exam text for readers with different needs. Its reading controls run locally without an account. Optional Gemini simplification sends only the chosen question and reading profile to Google after explicit consent and a click; the original question and marks stay unchanged.

FAQ

Does it need internet?

The reading controls work without internet once this page is open. Download the project to reopen it offline. Optional Gemini rewording needs a connection and the configured server. A local guide remains available without them.

Does read-aloud work on every laptop?

It uses locally installed browser voices only. If none are available, Exam Reader switches to a timed follow-along highlight. It never uses an online voice service.

Does it change the question paper?

Never. It only changes presentation: size, spacing, colour, chunking and focus. Question numbers and marks are preserved.

Where is my text stored?

Nowhere. Text is processed in memory only. Only your display settings are saved on your own device.
